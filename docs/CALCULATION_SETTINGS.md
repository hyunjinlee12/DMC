# Calculation settings — full audit trail

All settings currently in use across the pipeline, extracted from the actual
INCAR/KPOINTS/POTCAR files in the repo. This is the document to review
before submitting any batch to another server.

> **Status**: audit-ready. Generated 2026-07-17; source commit visible via
> `git log docs/CALCULATION_SETTINGS.md`. Live per-candidate DFT status is
> tracked in `paper_data/07_dft_results.csv` (auto-regenerated by
> `scripts/build_paper_data.py`) — not duplicated here.

Common convention:
- **Functional**: PBE + D3(BJ) (`IVDW = 12`).
- **POTCAR**: PAW_PBE, **Pd_pv** (semicore 4p, 16 valence electrons), C, H, O
  (all standard PAW_PBE). See §11 for exact TITEL / release-date provenance.
- **Cutoff**: `ENCUT = 520 eV`, `PREC = Accurate`, `LASPH`, `ADDGRID`, `LORBIT = 11`.
- **Spin (revised)**: `ISPIN = 2` for all condensed-phase (bulk, slab,
  ads-slab). `ISPIN = 1` for closed-shell isolated molecules (CO, CH₃OH, H₂);
  `ISPIN = 2 + NUPDOWN = 1` for the open-shell CH₃O radical. **MAGMOM
  initialization policy for condensed-phase is currently under seed-test
  audit** in `calculations/magnetic_seed_test/` — see §12. Until that test
  completes, T1.17 templates leave MAGMOM at VASP default (1.0 μ_B/atom)
  to match T1.16 for internal consistency, with the caveat that the
  resulting magnetic state has been shown to distribute moments throughout
  the slab (not surface-localized), suggesting a possibly metastable FM
  solution that must be validated against nonmagnetic and low-moment
  alternatives.
- **D3 flavour**: Becke-Johnson damping (`IVDW = 12` is D3-BJ in VASP 6.x).

## 6. Gas-phase references (for T1.18 μ_gas)

`calculations/gas_references/`. Isolated molecule in a cubic vacuum box.

Common:
- ENCUT 520, PREC Accurate, LASPH, ADDGRID, IVDW=12 — **identical to slab
  settings** so systematic PBE-D3 error cancels in ΔG_ads formula.
- NCORE 1, LREAL Auto, ISYM 0.
- **ISMEAR = 0, SIGMA = 0.01** (very sharp — isolated molecule).
- **EDIFFG = -0.01** (tighter than slab, since molecule geometry sensitive).
- KPOINTS **explicit Γ-only file** (1×1×1 Γ, no KSPACING active).
- box side 15 Å cubic (primary); 20 Å variants for polar molecules (CH₃OH, CH₃O)
  as paired-static box-size sanity checks.
- **Dipole correction (LDIPOL/IDIPOL) is off**. Rationale: polar molecules
  (CH₃OH, CH₃O) DO carry a dipole, but the paired-static 15 Å + 20 Å boxes
  bracket the periodic-image error explicitly. If the two static energies
  agree within 5 meV, the box is large enough that the periodic-image
  interaction is negligible; if not, we would enlarge the box (not turn on
  dipole correction, which introduces its own subtleties for isolated
  molecules).

  semicore) throughout, per project decision.

## 8. Convention summary for ΔG (T1.18 post-processing) — REVISED

The two coupled requirements:

**(a) Adsorbed slab and clean slab must use the same environment and identical
computational settings.** This is the internal consistency that lets the
substrate energy cancel exactly in the difference `G(slab+ads) − G(slab)`.

**(b) Molecular reservoirs are defined by the actual physical supply**
(gas, dissolved species, pure liquid, CHE), independently from the environment
used for the slab. They do NOT have to be in the same VASPsol/vacuum state as
the slab.

Formally, for an environment `env ∈ {vacuum, implicit_methanol}`:

```
ΔG_CO*^env   = G(slab+CO)^env  − G(slab)^env  − μ_CO^reservoir
ΔG_CH3O*^env = G(slab+CH3O)^env − G(slab)^env − μ_CH3O^reservoir
```

with the reservoir chemical potentials defined by the physical setup:

| species | reservoir choices | how to compute |
|---|---|---|
| CO | gas feed | `μ_CO(g) = G(CO)_gas + kT·ln(p/p⁰)` — takes gas-phase E |
| CO | dissolved | `μ_CO(g) + Δμ_solvation(CO, methanol)` |
| CH₃OH | pure liquid @ activity 1 (usual for methanol solvent) | `G(CH₃OH)_gas + RT ln(p_sat(T)/p°)` (see sign note below) OR `G(CH₃OH)_liquid` from AIMD |
| CH₃OH | gas feed | `G(CH₃OH)_gas + kT·ln(p/p⁰)` |
| H₂ | CHE (½ μ_H₂(g) at pH=0, U=0 SHE) | `½ G(H₂)_gas` — always the gas reference |
| CH₃O radical | auxiliary reference | `G(CH₃O)_radical` — use only if the MeOH(U) formula is unwanted |

CHE with methanol reservoir (workplan preferred for T1.19 descriptor map):

```
ΔG_CH3O*(U) = G(slab+CH3O)^env  +  ½ μ_H₂(g)
              − G(slab)^env
              − μ_CH₃OH(reservoir)   (liquid or gas, whichever matches the experiment)
              − eU
```

CH₃OH from `CH3OH_vaspsol` gives an electronic energy in implicit methanol —
this is NOT directly the liquid chemical potential. To use it as a liquid
reservoir at activity 1, add a **liquid-standard-state correction**. Using the
vapour-pressure relation

```
μ_CH₃OH(l, T) = μ_CH₃OH(g)°(T) + RT ln(p_sat(T)/p°)
```

with methanol `p_sat ≈ 0.169 bar` at 298.15 K (NIST Antoine parameters) and
`p° = 1 bar`, gives

```
μ_CH₃OH(l) − μ_CH₃OH(g)°  ≈  RT ln(0.169) ≈ −4.40 kJ/mol   (NEGATIVE at 298 K)
```

That is, liquid methanol at activity 1 has a **lower** chemical potential than
the 1 bar ideal gas reference at ambient T, because the saturation vapour
pressure is below the standard pressure. **Do not add +ΔG_vap** as an earlier
draft of this doc suggested — the sign is negative.

Alternative: extract μ_CH₃OH(l) from AIMD of liquid methanol, which bypasses
the ideal-gas approximation but costs an extra simulation.

Take `μ_CH₃OH` as gas reference if the experiment supplies methanol from a
gas phase. **The choice must be recorded in the paper_data/ metadata** — this
is the biggest open decision left for T1.18.

**Not required**: matching `env` between adsorbed slab and reservoir. The
requirement is matching `env` between adsorbed and clean slab. Mixing a
`vaspsol` slab pair with a `μ_CO(gas)` reservoir is physically correct if the
experiment supplies CO from a gas phase.

Free-energy corrections to be added at analysis time (ASE Thermochemistry):
- Adsorbate: **harmonic approximation** (finite-difference frequency calc, IBRION=5)
- Gas molecule: **ideal-gas** (rotational + translational + vibrational, with
  molecular symmetry number)
- Liquid methanol: gas ideal-gas + vaporisation ΔG (from Antoine equation or table).

  ratio ~0.25). Also seed-suspicious — the fixed atoms retained
  default 1.0 μ_B initialization more strongly because they never
  ionic-relaxed. Physical vs. artifact remains open until seed test runs.

**Decision rule** once test completes:
- All seeds → same E and moment: adopt that state, MAGMOM policy fixed.
- One seed clearly lower: adopt it, regenerate T1.17 templates with matching
  MAGMOM init.
- Seeds within ~10 meV: record as magnetic uncertainty in downstream ΔG.
- Multiple basins: NUPDOWN fixed-spin scan to map, propagate largest gap
  as systematic error bar.

Until decision: T1.17 MAGMOM = VASP default (matches T1.16). Do NOT change
the pending 79 T1.16 calcs — they are screening and mixing MAGMOM
initializations within the screening batch would break intra-group ranking.
